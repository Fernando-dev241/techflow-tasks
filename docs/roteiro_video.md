# Roteiro do Vídeo Pitch (até 4 minutos)

Grave a tela (OBS, Loom ou Meet) com sua voz. Publique no YouTube (não listado) ou no Drive com
link público e cole o link no documento teórico e no README.

| Tempo | O que mostrar | O que falar (sugestão) |
|-------|---------------|------------------------|
| 0:00–0:25 | Rosto/slide com o título | "Olá, sou [nome]. Vou apresentar o TechFlow Tasks, sistema de gerenciamento de tarefas que desenvolvi como desenvolvedor e gestor ágil da TechFlow Solutions para uma startup de logística." |
| 0:25–1:00 | README no GitHub | Objetivo, escopo inicial e o que ficou fora (login, banco de dados). |
| 1:00–1:35 | Quadro GitHub Projects | "Usei Scrumban: Kanban com To Do, In Progress e Done, WIP de 3 cards e revisões curtas. Cada card é uma issue ligada a um commit." |
| 1:35–2:25 | `python run.py` e navegador | Criar tarefas, mover entre colunas, excluir, escolher prioridade e filtrar por *Crítica*. |
| 2:25–3:00 | Pasta `tests/` e `pytest -v` | "São 30 testes: validações, CRUD, erros 400/404, ordenação e filtro de prioridade." |
| 3:00–3:25 | Aba **Actions** | Mostrar o workflow verde: flake8 + pytest em Python 3.11 e 3.12. |
| 3:25–3:45 | README (Gestão de Mudanças) + card #11 | "O cliente pediu priorização. Criei o card, implementei, testei e atualizei UML e README, sem mexer no fluxo existente." |
| 3:45–4:00 | Rosto/slide final | Reflexão: a Engenharia de Software reduz retrabalho, dá previsibilidade e permite mudar com segurança. |

**Dicas:** ensaie uma vez com cronômetro, deixe o servidor já rodando e use zoom no navegador (125%).
